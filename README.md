# Toeic金フレ特急

個人学習用の、インストール不要で動くTOEIC® L&R向け単語帳Webアプリです。

提供された写真100枚から、No.001〜1000の全1000語を初期収録しています。

- Score 600 Level：No.001〜400
- Score 730 Level：No.401〜700
- Score 860 Level：No.701〜900
- Score 990 Level：No.901〜1000

## 起動方法

`index.html` をChromeやEdgeで開いてください。インストールやアカウント登録は不要です。

## 主な機能

- 見出し語と英語例文を見て、見出し語の意味を選ぶ4択クイズ
- 正解・不正解のどちらでも、正しい語義と例文訳を表示
- 「分からない」を選ぶと不正解として記録し、間違えた問題へ追加
- 登録済み単語からランダムに作る選択肢
- 忘却曲線を意識した復習スケジュール
- 全1000語から毎回完全ランダムに選ぶ10問学習、復習待ち、苦手語の集中学習
- レベルを問わず、一度でも間違えた問題だけをまとめて復習
- 600点・730点・860点・990点のレベル別復習、レベル別の復習率表示
- 各レベルで一度でも間違えた問題だけを集めた復習
- 英語音声の読み上げ（ブラウザの音声機能を使用）
- 単語の追加・編集・検索・レベル絞り込み
- スマートフォンのカメラ／写真から英単語・意味・例文をOCRで抽出
- 『TOEIC L&R TEST 出る単特急 金のフレーズ 増補改訂版』向けの専用認識・確認画面
- 習得語数、正答率、今日の回答数の表示
- PC・スマートフォン対応
- スマートフォンの復習画面はスクロール不要の1画面表示

データはブラウザのLocalStorageに保存されます。単語・学習履歴・選択した写真は外部へ送信されません。ブラウザデータを消去すると学習履歴も消えるためご注意ください。

## 写真から追加

「データ管理」→「カメラ・写真から追加」から利用できます。

1. カメラで1枚ずつ追加するか、写真ライブラリから最大10枚をまとめて選択
2. 写真の向きは自動判定。必要な場合だけ90度回転や左右ページを指定
3. 「この写真を読み取る」を押す
4. 抽出候補の誤認識を修正し、チェックした単語を追加

配布サイズを抑えるためOCR本体は同梱していません。写真OCRを初めて使う際はインターネット接続が必要です。Tesseract.jsと軽量英日言語データを取得した後、文字認識は端末内で実行され、写真自体はアップロードされません。
